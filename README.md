# 春秋戰國：列國爭霸

一款在瀏覽器中遊玩的 3D 即時戰略遊戲（類《世紀帝國》），以中國**春秋戰國**時代為背景。
選擇戰國七雄之一（秦、楚、齊、燕、趙、魏、韓），採集資源、建設城邑、訓練軍隊、研究百家學說，摧毀敵國以一統天下。

純前端、零建置步驟：HTML + ES Modules + [three.js](https://threejs.org/)（已內附於 `vendor/`），介面全為繁體中文。

## 如何遊玩

### 方法一：本機啟動靜態伺服器（建議）

```bash
# 任選其一
npx serve .
python3 -m http.server 8000
```

然後在瀏覽器開啟 `http://localhost:8000/`（或指令顯示的網址）。

### 方法二：直接開啟單一檔案

執行 `node build.js` 會產生 `dist/index.html`，把所有程式碼與 three.js 打包成一個檔案，
可直接雙擊以 `file://` 開啟遊玩（不需要伺服器）。

### 方法三：GitHub Pages

儲存庫內附 `.github/workflows/deploy-pages.yml`。在 GitHub 的 **Settings → Pages** 將 Source 設為 **GitHub Actions**，
之後每次推送至 `main` 分支就會自動部署，可直接在線上遊玩。

## 操作方式

| 操作 | 說明 |
| --- | --- |
| 左鍵點擊 / 拖曳 | 選取單位（Shift 加選、雙擊選取畫面上同類單位） |
| 右鍵 | 依目標執行移動、攻擊、採集、建造、修理；選取生產建築時可設定集結點 |
| 方向鍵 / WASD / 滑鼠靠近螢幕邊緣 | 移動視角 |
| Q / E 或按住中鍵拖曳 | 旋轉與俯仰視角 |
| 滾輪 | 縮放 |
| H | 跳到都城 |
| `.`（句點） | 選取閒置農民 |
| Ctrl + 1~9 / 1~9 | 設定與選取編隊（連按兩次跳至該編隊） |
| A 後點擊 | 攻擊移動（沿途攻擊敵人） |
| S | 停止 |
| Delete | 刪除所選單位 |
| Esc | 取消建造 / 取消選取 |
| 空白鍵 | 暫停 |
| F1 | 操作說明 |
| 小地圖 | 左鍵移動視角、右鍵命令所選單位前往 |

指令面板上每個按鈕都標有快捷鍵，滑鼠停留可查看說明與成本。

## 遊戲內容

### 資源與時代

四種資源：**糧食、木材、石材、黃金**。農民可採集漿果叢、農田、樹木、石礦與金礦，並送回都城、糧倉、伐木場或礦場。

| 時代 | 條件 | 解鎖 |
| --- | --- | --- |
| 春秋時代 | 起始 | 戈兵、弓兵、戰車、基礎建築 |
| 戰國時代 | 糧倉 + 兵營，500 糧 300 木 | 劍士、弩兵、騎兵、衝車、學宮、市集、攻城坊 |
| 七雄爭霸 | 學宮 + 市集，900 糧 500 金 | 投石車、鐵兵器、孫子兵法 |

### 戰國七雄

| 國家 | 特色加成 |
| --- | --- |
| 秦 | 步兵攻擊 +15%，「商鞅變法」免費 |
| 楚 | 木材採集 +25%，戰車成本 -20% |
| 齊 | 黃金採集 +20%，學宮科技成本 -25% |
| 燕 | 弓兵與弩兵射程 +1，箭樓成本 -30% |
| 趙 | 騎兵耐久 +20%，「胡服騎射」免費 |
| 魏 | 劍士耐久 +20%，步兵訓練速度 +25% |
| 韓 | 弩兵攻擊 +20%，「韓國勁弩」免費 |

### 單位

農民、戈兵（克制騎兵與戰車）、劍士、弓兵、弩兵、戰車（克制遠程）、騎兵、衝車（攻城）、投石車（範圍傷害）。

### 建築

都城、民居、糧倉、伐木場、礦場、農田、兵營、弓弩坊、馬廄、攻城坊、學宮、市集、箭樓、城牆。

### 學宮科技

鐵器農具、商鞅變法、胡服騎射、墨家守城、韓國勁弩、鐵兵器、孫子兵法。

### 勝負

摧毀敵國所有建築（城牆與農田除外）並消滅其農民即獲勝；己方遭受相同命運則落敗。
敵國 AI 會自行發展經濟、進入新時代、研究科技，並定期發動進攻，可於開始畫面選擇難度（簡單 / 普通 / 困難）與地圖大小。

## 專案結構

```
index.html      頁面與介面骨架
style.css       介面樣式
src/data.js     單位、建築、科技、國家等資料定義
src/world.js    地形生成、格狀阻擋、A* 尋路
src/meshes.js   以基本幾何體程序化生成的中式建築與單位模型
src/game.js     遊戲核心：經濟、建造、訓練、戰鬥、勝負判定
src/ai.js       敵國 AI
src/input.js    相機、選取、指令與建造放置
src/ui.js       HUD、指令面板、小地圖
src/sfx.js      合成音效
src/main.js     進入點
build.js        打包成單一 HTML（dist/index.html）
vendor/         three.js（MIT 授權）
```
